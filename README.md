## 🎮 About the Game

Microsoft Flight Simulator is a flight simulation game developed by Asobo Studio and published by Xbox Game Studios. The 2020 edition launched on August 18, 2020, while the free 40th Anniversary Edition update released on November 11, 2022. It simulates aircraft operations across a detailed, globe-spanning world with live weather, air traffic, navigation, and realistic flight physics.

## 🔥 Project Overview

**This tool** is a comprehensive trainer for **Microsoft Flight Simulator (2020) 40th Anniversary Edition**. This trainer provides optional convenience controls for Microsoft Flight Simulator, including flight-state management, simulation pausing, aircraft positioning, weather and time adjustments, and selected assistance features. It is designed for flexible free-flight sessions, testing, sightseeing, and practice without changing the game's core aircraft systems.

**Target Audience:** Suitable for flight-simulation enthusiasts, newcomers practicing aircraft handling, users testing helicopters or gliders, virtual pilots exploring the world, and creators preparing screenshots or demonstrations in Free Flight.

## 📖 Detailed Feature Guide

### Movement & Exploration

Use the trainer's position controls only when the aircraft is stable or the simulation is paused. Position changes are useful for setting up approaches, relocating to a landmark, or recovering from an unsuitable starting point. Normal aircraft movement remains governed by the selected aircraft's flight model, control bindings, trim, engine controls, and autopilot.

### Tools & Inventory

There is no conventional inventory system in Microsoft Flight Simulator. Aircraft, airports, scenery, flight plans, weather presets, and assistance settings are selected through the simulator's menus rather than collected or managed as carried items.

### World & Environment

The simulator provides a worldwide environment based on geographic data, detailed airports, live or preset weather, changing time of day, air traffic, and multiplayer options. Trainer controls can help configure time, weather, and location for repeatable sightseeing, navigation practice, and approach training.

### Combat & Weapons

There is no standard combat system, weapon inventory, or combat progression in the 2020 edition. The trainer is intended for civilian flight simulation, aircraft testing, navigation, sightseeing, and practice rather than combat encounters.
